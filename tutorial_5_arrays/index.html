01 / VISIT EVERY ITEMforEach()

The full table

Every restaurant, with its cuisine. Run one action for each record.

Your full restaurant list will appear here.

How forEach works

Visits all eight records to create DOM elements. It returns undefined, so it is useful for actions rather than creating a new array.

restaurants.forEach((restaurant) => {
  list.append(createRestaurantRow(restaurant));
});
02 / KEEP THE MATCHESfilter()

A smaller bill

Only $ and $$ restaurants. Keep the records that meet the budget.

Your affordable picks will appear here.

How filter works

Returns a new array of five matching records. The original array keeps all eight. Records are shared references, not deep copies.

restaurants.filter((restaurant) => {
  return restaurant.priceRange === "$" ||
    restaurant.priceRange === "$$";
});
03 / TRANSFORM THE ITEMSmap()

Just the names

Eight records become eight strings. A simple list without the extra detail.

Your list of names will appear here.

How map works

Returns a new array containing only name strings, in the original order. The records remain unchanged.

restaurants.map((restaurant) => {
  return restaurant.name;
});
04 / RETURN ONE MATCHfind()

The 4.8 pick

Find the first restaurant rated exactly 4.8 and see its details.

Your featured restaurant will appear here.

How find works

Returns The Brass Elephant, the first matching record. It returns undefined if no rating matches. This is an exact rating lookup, not a general maximum calculation.

restaurants.find((restaurant) => {
  return restaurant.rating === 4.8;
});
Different intent. Same source.

filter selects. map transforms. find looks up one record. forEach performs an action. These examples change the presentation without changing the restaurant data.
